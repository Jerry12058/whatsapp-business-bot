# WhatsApp Business Auto-Reply Bot

## What this is
A small server that:
1. Receives WhatsApp messages sent to your business number
2. Automatically replies based on simple keyword rules (edit these in `server.js`)
3. Saves every customer's name, number, and message so you can review them later (visit `/customers` once it's running)

## Files in this project
- `server.js` — the actual program (you don't need to understand the code to use it)
- `package.json` — a list of tools the program needs to run
- `.env.example` — a template showing which secret values you'll need to add later
- `.gitignore` — tells GitHub which files to skip uploading (keeps secrets safe)
